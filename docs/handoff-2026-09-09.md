- Cosmos JSON-schema grammar (`--json-schema`): zero out-of-vocabulary labels,
  p95 3.36 s, but six "person" detections on people-free footage fired seven

  the original `<answer>`-wrapper prompt the grammar collapsed output to an
  empty list every frame (`..._schema_v1prompt.json`), kept as evidence.
- vLLM 0.14 pitfall: `response_format` json_schema is silently NOT enforced
  when `--reasoning-parser qwen3` is on. Use the `cosmos2b-vllm-noreason`
  container for constrained runs.
